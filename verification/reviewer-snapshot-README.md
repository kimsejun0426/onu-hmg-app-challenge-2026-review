우리 자동차가 아이의 여정에 함께하는 친구가 되도록 돕는 한국어 음성 이야기 앱입니다.

## 심사 자료

- [설치 APK](apk/오누_오누_release.apk) — 0.47.0 / versionCode 49
- 소개 영상은 별도 제출 파일로 제공합니다. 이 ZIP은 설치 APK와 대응 소스의 재현용 묶음입니다.
- [빌드 안내](BUILD.md) · [검증 범위](VALIDATION.md) · [출처와 권리](RIGHTS.md)
- [소스 파일 해시](source-file-manifest.json) · [전체 파일 해시](submission-manifest.json)

APK는 최종 입력 목록과 같은 바이트의 소스에 대응합니다. 설치·재생·인식의 실제 확인 범위는
검증 보고서를 기준으로 읽어 주세요. 일반 Android 설치 성공이 Pleos 음성 인식이나 실차
주행 지원을 뜻하지 않습니다. 주행 중 음성 동행은 필수 목표이며 현재 플랫폼 허용 범위는
보고서에 구분합니다. 원음·차내 대화 전문을 수집하는 상시 녹음 기능을 뜻하지 않습니다.

## 제출 상태

이 폴더는 로컬 제작물입니다. 원격 업로드·심사자 접근 확인·공식 접수 완료를 주장하지 않습니다.
소개에는 팀명만 쓰며 신청서·개별 연락처·동의·서명 자료는 포함하지 않았습니다.
앱에 필요한 공개 운영자·문의 고지는 원본 소스에 보존하므로 완전 익명화라고 표시하지 않습니다.

## 소스 구성

apps/vehicle는 앱과 시험, content는 이야기, packages/services/tests/tools는 계약·참조 구현과
검증 도구입니다. ci/verify-workflow.yml.example은 자동 실행되지 않는 CI 참고본입니다.
Git 이력, 캐시, SDK 바이너리, 실행 데이터베이스, 서명 자료는 포함하지 않습니다.
