# 별빛 우체국 · 콘텐츠 검수 기록

**0.7.0 편집 · 2026-10-27.** 읽어 주기 선택 뒤에는 모모가 편지를 펼치는 준비만 말하고, 실제 읽기와 고른 인사는 결말에서 한 번 전달한다. 0.11 배포 APK의 0.6.0 원문과 카탈로그 메타데이터는 보존했다. 장면·행동 ID, 분기·점수·자원·단서·flag·출처와 결말 본문은 유지한다. 글로벌 기다림·거절·쉬기와 무응답 정책은 바꾸지 않았다. 아래는 이전 판의 검수 기록이며 실제 가족 청취·교육 효과 검증을 뜻하지 않는다.

**0.5.0 편집 · 2026-10-27.** 상상 속 배달 초대를 분명히 하고, 인사를 고르는 질문을 하나로 묶었다. 고른 길·수신인·인사가 마지막 배달과 오누의 배웅에 남는다. 0.4.0 원문은 바이트 그대로 보존했고, 기존 행동 ID·별칭·분기·점수·자원·단서·flag·출처는 바꾸지 않았다. 새 입력 기능이나 교육 효과 주장을 추가하지 않았으며, 실제 가족 청취 평가는 미실시다. 아래는 0.3.0 당시의 검수 기록으로, 그때의 문구·시험 수를 이번 판의 결과로 읽지 않는다.

`starlight-post-office` `0.3.0` · 한국어 · 2026-10-27

바람에 날린 별편지를 우체부 모모와 찾아 배달한다. 오누는 곁에서 함께 찾고 발걸음을 맞추는 동행자다. 달다리에서는 달집의 작은 곰에게, 바람정원에서는 바람집의 토끼에게 가는 봉투를 발견한다. 다른 아이의 감정이나 실제 가족의 상황을 추정하지 않는다.

여섯 행동은 길 → 봉투 단서 → 모모 돕기 → 문패 확인 도구 → 우리 인사 → 전달 방식이다. `0.2.0`의 장면·선택 ID, 화면 선택 이름, 별칭, 다음 장면·조건 분기, 점수·자원·단서·기존 flag는 유지한다. 새 `address_source` flag는 도장을 보았는지 쪽지를 읽었는지만 남긴다. 그 선택이 문패를 무엇과 맞춰 보는지에 이어지고, 동행 방식은 집 앞 도착 대사, 도구는 인사 쓰기 장면에 반영된다. 선택 목록을 마지막에 몰아 읽지 않는다.

모모는 처음 가는 집이라 떨린다고 직접 말한다. 나란히 걷기와 앞길 살피기는 서로 다른 행동이며 어느 쪽도 더 좋은 마음으로 평가하지 않는다. 인사와 전달 방식에도 정답을 두지 않는다. 받는 친구가 편지함에 놓아도 함께 읽어도 괜찮다고 명시한다. 조용한 배달(`QUIET_DELIVERY`)과 함께 읽기(`SHARED_READING`) 모두 완성된 배달이며, 세 문장 결말은 실제 고른 길·수신인·인사·전달 방식을 되짚는다.

모든 경로는 총 6점, 두 명이면 각 3점이다. 힌트는 여섯 장면에서 각각 사용할 수 있고 감점은 없다. 같은 장면의 힌트 반복은 추가 차감하지 않는다. 도움 요청이나 감정 표현의 우열을 점수로 정하지 않는다. 한 명은 별빛 배달부, 두 명은 길잡이와 마음지기가 번갈아 세 번씩 선택한다. 역할은 차례 귀속이며 실제 화자 인증이 아니다.

별편지·말하는 동물·배달 도구는 허구이며 새 과학 사실이나 교육 효과를 추가하지 않는다. 실제 편지 전송·자유 대화·감정 추론 기능을 뜻하지 않는다. 장면의 prompt·hint·summary는 저장된 flag의 템플릿을 사용한다. 행동 feedback은 렌더되지 않는 고정 문장이므로 템플릿을 넣지 않는다.

`tests/test_content_stories_animals.py`는 반대 길·봉투 확인 방법·동행 방식·도구·인사 선택이 실제 후속 안내나 결말을 바꾸는지 검사한다. 두 인원수의 128경로에서 여섯 행동·원래 결말·점수·자원·단서·history와 힌트 무감점을 비교하며, 질문은 장면당 하나이고 결말은 세 문장인지 확인한다. 실제 한국어 TTS 청취·가족 사용성·특정 연령 적합성은 아직 검증하지 않았다. 약 4–6분은 예상이며 대기·힌트·재생 속도에 따라 달라진다.
