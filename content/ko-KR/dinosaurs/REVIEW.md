# 공룡 연구소의 사라진 알 — 콘텐츠 검수 기록

**0.7.0 편집 · 2026-10-27.** 도구 선택 결과에서 뿔 단서의 중복을 덜고 다음 질문에 전체 단서를 남겼다. 다시 듣기와 이어하기에서도 두 공룡 선택과 뿔 단서를 확인할 수 있다. 0.11 배포 APK의 0.6.0 원문과 카탈로그 메타데이터는 보존했다. 장면·행동 ID, 분기·점수·자원·단서·flag·출처와 결말 본문은 유지한다. 글로벌 기다림·거절·쉬기와 무응답 정책은 바꾸지 않았다. 아래는 이전 판의 검수 기록이며 실제 가족 청취·교육 효과 검증을 뜻하지 않는다.

**0.5.0 편집 · 2026-10-27.** 첫 장면을 오누와 떠나는 상상 탐험으로 열고, 고른 길·흔적·도구가 로봇 발견과 귀환 대사에 이어지게 다듬었다. 0.4.0 원문은 바이트 그대로 보존했고, 기존 행동 ID·별칭·분기·점수·자원·단서·flag·출처는 바꾸지 않았다. 새 입력 기능이나 교육 효과 주장을 추가하지 않았으며, 실제 가족 청취 평가는 미실시다. 아래는 0.3.0 당시의 검수 기록으로, 그때의 문구·시험 수를 이번 판의 결과로 읽지 않는다.

현재 콘텐츠는 `0.3.0`이다. 초면의 6–9세, 혼자 또는 둘이 듣는 상황은 설계 가정이며 실제 아동의 난도·재미·발음 검증을 마쳤다는 뜻이 아니다. 과거 `0.1.0`과 `0.2.0` 저장 모험은 각 보존본으로 이어 간다.

## 작은 목표와 선택의 회수

빈 전시대의 알 모형을 되찾기 위해 운반 로봇을 찾는다. 길 → 흔적 → 먹이 표시 → 도구 → 로봇 그림 → 목적지의 여섯 선택은 유지했다. 먹이와 뿔 질문을 별개의 상식 시험으로 두지 않고, 로봇을 알아보는 표시로 연결했다.

물가/숲은 조사 경로와 알 모형의 목적지를 바꾼다. 바퀴 자국/상자 표지 선택은 `evidence_method`에 남겨 마지막 질문과 힌트에서 다시 불러 준다. 돋보기/듣기 장치는 기존 `tool_used`에 따라 다음 질문의 관찰 문장과 결말에 나타난다. 마지막 질문은 목적지를 다시 말해 주므로 앞 장면을 모두 외워야만 진행할 수 있지는 않다. 오누는 단서를 같이 짚거나 도구를 잡는 역할을 맡으며 아이를 평가하는 교사로 말하지 않는다.

직접 발견(`FOUND_TOGETHER`)과 연구소 팀의 도움으로 발견(`TEAM_ASSIST`) 모두 알 모형이 전시대로 돌아온다. 도움 결말을 실패라고 부르지 않고, 결말은 쉬어도 된다는 말로 끝낸다.

## 실제 지식과 허구

- 연구소, 운반 로봇의 표시, 노트, 목적지와 전시용 알 모형은 허구다.
- 실제 지식은 트리케라톱스의 식물성 먹이와 얼굴의 뿔 세 개, 스테고사우루스의 등에 있는 판으로 제한했다. 이번 개정에서 과학 사실과 출처를 추가하거나 바꾸지 않았다.
- 출처는 [Natural History Museum의 Triceratops](https://www.nhm.ac.uk/discover/dino-directory/triceratops.html), [Stegosaurus](https://www.nhm.ac.uk/discover/dino-directory/Stegosaurus.html)이며 원본의 확인 날짜는 2026-10-24다. 그림·음원·문장은 복제하지 않았다.

## 규칙과 검증 범위

장면·행동·결말 ID, 선택 별칭, 분기, 내부 점수, 자원 비용, 기존 단서와 flag는 보존했다. 한 명이면 여섯 번, 두 명이면 각 세 번 선택한다. 내부 최대 점수는 합계 8점, 두 명이면 각 4점이다. 다른 지식/목적지 선택에 기존의 0점 결과가 남아 있으므로 모든 선택의 내부 점수가 같다고 주장하지 않는다. 점수는 능력 평가가 아니며 이야기 대사에서 성적처럼 말하지 않는다.

힌트는 여섯 개이고 감점하지 않는다. 같은 장면에서 다시 들어도 추가 차감하지 않는다. 불명확한 표현이나 잘못된 차례는 확정 행동이 아니므로 점수·자원을 바꾸지 않는다. 쉬기·다시 듣기 등 기존 제어는 콘텐츠 개정 범위 밖이며 그대로 사용한다.

`tests/test_content_dinosaurs_ocean.py`는 두 경로·관찰 방법·도구가 후속 질문과 두 결말에 반영되는지, 질문과 힌트의 목적지가 일치하는지, 1인/2인 모두 여섯 행동으로 끝나는지 확인한다. 기존 0.2.0과 모든 경로의 분기·점수·자원·기존 단서도 비교한다. 자동 시험은 실제 아이의 재미나 한국어 TTS 이해도를 입증하지 않는다. 가족 청취·중간 복귀·겹쳐 말하기·낯선 공룡 이름 발음은 별도 검증이 필요하다.
