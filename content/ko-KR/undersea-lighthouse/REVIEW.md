**0.5.0 편집 · 2026-10-27.** 표지와 도구의 회수를 유지하면서 마지막 모양 넣기와 등대로 빛 보내기를 오누가 함께 하는 짧은 행동으로 표현했다. 두 결말은 누리의 응답과 오누의 인사로 닫는다. 0.4.0 원문은 바이트 그대로 보존했고, 기존 행동 ID·별칭·분기·점수·자원·단서·flag·출처는 바꾸지 않았다. 새 입력 기능이나 교육 효과 주장을 추가하지 않았으며, 실제 가족 청취 평가는 미실시다. 아래는 0.3.0 당시의 검수 기록으로, 그때의 문구·시험 수를 이번 판의 결과로 읽지 않는다.

현재 콘텐츠는 `0.3.0`이다. 초면의 6–9세, 혼자 또는 둘이 듣는 상황은 가상 설계 페르소나이며 실제 아동 시험 결과가 아니다. 과거 `0.1.0`과 `0.2.0` 저장 모험은 각 보존본으로 이어 간다.

## 작은 목표와 선택의 회수

잠수정 누리가 돌아갈 수 있도록 등대 불빛을 켠다. 길 → 표지 관찰 → 단서 챙기기 → 도구 → 마지막 모양 → 등대의 여섯 선택을 유지했다. 산호문은 동쪽 등대와 “동그라미, 세모, 동그라미”, 조개터널은 서쪽 등대와 “세모, 동그라미, 세모”로 이어진다.

표지 보기/부표 듣기는 `sign_method`에 남겨 다음 질문에서 관찰 방식을 다시 말한다. 지도 펴기/표지 되짚기는 기존 `teamwork`에 따라 신호판을 찾는 문장을 바꾼다. 빛거울/메아리 조개는 기존 `tool_used`에 따라 마지막 모양 질문과 두 결말에 다시 나타난다. 오누는 지도를 펼쳐 두거나 옆에서 단서를 짚는 짧은 행동으로 동행한다.

모양 선택 직전에는 순서를, 목적지 선택 직전에는 등대 이름을 다시 준다. 중간에 쉬거나 차례가 바뀌었을 때 앞 내용을 외워야만 이어 갈 필요가 없다. 다른 모양이면 불이 깜빡이는 결과와 약속에 맞춰 고치는 과정을 설명하며, 추가 선택을 요구하지 않는 기존 분기를 유지했다.

목적지에 직접 신호를 보내는 결말(`LIGHT_CONNECTED`)과 다른 등대를 통해 이어 보내는 결말(`LIGHT_RELAY`) 모두 누리가 도착하고 불빛으로 답한다. 두 결말은 고른 도구와 실제 목적지를 기억한다. 다시 하라는 압박이나 실패자라는 표현은 쓰지 않는다.

## 규칙과 검증 범위

장면·행동·결말 ID, 선택 별칭, 분기, 내부 점수, 자원 비용, 기존 단서와 flag는 보존했다. 내부 최대 점수는 합계 8점이며 두 명이면 각 4점이다. 다른 모양/목적지 선택은 기존처럼 해당 행동의 내부 점수가 0점이므로 모든 선택의 점수가 같다는 뜻은 아니다. 힌트는 여섯 개이고 감점하지 않는다. 이야기에서 점수를 성적처럼 읽지 않는다.

한 명이면 바다 탐험가, 두 명이면 길잡이와 빛지기가 각 세 번 선택한다. 필요한 단서는 음성 문장에 들어 있다. 색 구별이나 화면 주시, 실제 방향 감각을 요구하지 않는다. 등대·부표·조개·신호 규칙·잠수정은 모두 허구이고, 모양의 순서는 이야기의 약속이며 실제 항해 지침이 아니다. 새 해양 과학 사실은 추가하지 않았다.

`tests/test_content_dinosaurs_ocean.py`는 양쪽 경로, 관찰 방법, 협력 방법, 도구, 직접/중계 결말과 모양 수정 경로를 확인한다. 질문과 힌트의 모양·목적지가 일치하고 현재와 0.2.0의 모든 경로에서 분기·점수·자원·기존 단서가 유지되는지도 비교한다. 자동 시험과 실제 가족의 재미·한국어 TTS 이해도는 구분한다. 실제 청취 시간, 쉬었다 돌아왔을 때의 이해, 두 아이의 차례 갈등은 후속 사용성 검증 대상이다.
