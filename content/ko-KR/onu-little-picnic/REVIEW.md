# 오누와 작은 소풍 · 콘텐츠 검수 기록

**0.4.0 편집 · 2026-10-29.** 마지막 질문에서 고른 풍경을 오누에게 “간직해 줘”라고 부탁할 수 있도록, 풍경/풍경을·조용히 유무·명시한 붙여쓰기의 정확한 요청 열두 개를 추가했다. D의 0.18 전달본 0.3.0 원문을 바이트 그대로 보존했다. 기존 대사·행동·결말·차례·별칭 및 해석 문법을 유지한다. 실제 아동 음성 인식이나 청취 평가 결과는 아니다.

**0.3.0 편집 · 2026-10-28.** 인사 결말의 기록 요약에서 ‘바람개비과’·‘나뭇잎 배과’·‘종이배과’를 각각 ‘바람개비와’·‘나뭇잎 배와’·‘종이배와’로 고쳤다. 기존 `toy` flag에 조사를 포함한 평면 `toy_with` label을 연결했다. ‘종이 연과’는 그대로이며 수정한 본문은 `ending_farewell.summary` 한 곳이다. 실제 낭독 대사·행동·별칭·분기·점수·자원·차례·역할과 장소·움직임 회상은 바꾸지 않았다.

실제 전달된 앱 0.15의 소풍 0.2.0 원고 14,084바이트와 카탈로그 메타데이터를 `content/legacy/0.2.0/onu-little-picnic/episode.json`에 보존했다. D의 APK 안 원고·카탈로그와 전달된 파일의 일치도 확인했으며 해시는 `tests/fixtures/published_onu_015_content.json`에 고정했다. 전용 `tests/test_content_particles.py`는 1인·2인 각각 16경로를 이전판과 비교해 네 놀이의 조사, 모든 상태 효과, 나머지 낭독·요약의 동일성을 확인한다. 새 판과 보존판 content checker도 각각 통과했다. 새 판의 Android 통합은 [앱 0.16 검증 보고서](../../../docs/verification-onu-0.16.0-2026-10-28.json)의 실제 203개 시험·APK·XML 해시를 따른다. 실제 아이·콘텐츠 TTS 청취 품질·가족 사용성 검증은 별도이며 이번 검사로 입증하지 않는다. 아래는 첫 판의 검수 기록이다.

`onu-little-picnic` `0.1.0` · `interest_tags: [stories]` · `play_style: imagine` · 2026-10-27

첫 문장에서 상상 속 소풍임을 밝힌다. 언덕·연못·소풍 가방·연·바람개비·배·바람과 물결의 움직임은 저작된 이야기이며, 실제 차량 상태나 주변 풍경을 인식한 결과가 아니다. 별도 등장인물이나 해결해야 할 시험을 더하지 않고 오누와 잠깐 함께 노는 장면을 만든다.

| 선택 | 이야기 속 결과 |
|---|---|
| 바람 언덕 / 잔잔한 연못 | 다음 장소와 고를 놀이가 달라진다. |
| 언덕의 종이 연 / 바람개비, 연못의 나뭇잎 배 / 종이배 | 오누가 고른 도구를 들거나 띄우며, 다음 질문과 결말에서 같은 도구를 다시 말한다. |
| 언덕의 높이 / 가까이, 연못의 큰 원 / 작은 원 | 연·바람개비가 바람을 만나는 자리나 배가 도는 범위가 달라지고 결말에 회수된다. |
| 인사 남기기 / 풍경 간직하기 | 오누의 짧은 인사 또는 마지막 풍경을 들려주는 두 결말로 이어진다. |

연줄·막대 잡기, 물결 보내기, 놀이 도구 챙기기는 모두 이야기 속 오누가 한다. 아이에게 차창 보기, 화면 주시, 몸동작이나 실제 물건 조작을 요구하지 않는다. 선택만 한 아이에게 실제 만들기·관찰·설명을 해냈다고 칭찬하지 않는다. 모든 행동은 내부 0점이고, 네 차례에서 사용할 힌트 네 개에 감점이 없다.

‘풍경 간직하기’도 작성된 종료 대사를 재생하고 기존 완료 흐름으로 끝난다. 별도의 무음·휴식·오디오 모드, 새 마이크 설정, 사진이나 음성 기록 저장 기능이 아니다. 쉬기·종료는 기존 앱 명령을 따른다. 이 편은 기존 콘텐츠 해석기를 사용하며 새 API, 음성 입력 문법이나 스크립트 실행 기능을 추가하지 않는다. 대사 외의 장면별 환경음·효과음 묶음, 자유 응답을 해석해 생성하는 대화, 사진 생성도 제공하지 않는다.

콘텐츠 검사기로 1인 16경로와 2인 16경로에서 네 차례·두 결말, 선택 별칭, 템플릿, 자원과 카탈로그 일치를 확인했다. Android와 전체 앱의 최종 검증 결과는 해당 릴리스 기록을 따른다. 약 3–4분은 측정된 이용 시간이 아닌 예상이다. 실제 가족 청취 평가는 미실시이며, 장소·도구·움직임을 화면 없이 따라갈 수 있는지, 네 번의 선택이 짧고 충분한지, 마지막 두 선택의 차이를 이해하는지는 검증할 가설이다. 교육·발달 효과나 특정 연령 적합성을 입증했다고 주장하지 않는다.
