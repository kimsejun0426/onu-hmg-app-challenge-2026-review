우리 자동차가 아이의 친구가 되도록 하는 한국어 음성 이야기 앱의 소개다. 실제 앱 화면 외의 차창·공룡·바다·빛선·캐릭터 움직임은 별도 일러스트 연출이다. 실차가 운행하는 촬영이나 실제 아동의 사용 모습을 포함하지 않는다. 외부 업로드와 공식 접수 완료를 뜻하지 않는다.

## 실제 화면과 연출

실제 UI는 최종 signed 0.47.0 APK에서 촬영한 세 구간, 합계 11.17초다. 앱 APK SHA256은 `d86beab971d9d286bb5f386c67e2064820cb4f12ea1c0fa991edc567ac591998`이며, 인사 원음과 효과음은 해당 APK 안의 음원과 바이트 일치를 확인했다. 첫 인사 미리듣기, 처음 설정에서 관심사 고르기, 저장된 이야기의 명시 이어하기를 구분한다. 관심사 컷은 새 시연 가족을 만든 뒤 처음 설정에서 공룡을 고르는 장면이다. 이어하기 컷은 버튼을 직접 누른 뒤 장면 준비와 읽기 질문·활성 다음 버튼까지 연속으로 보여 준다. 마이크 인식·실제 아동 응답을 촬영한 장면은 아니다. 실제 조작은 원래 속도로 연속 발췌하며, 화면 전체 비율을 보존한다.

- 실제 앱 화면 · 인사 미리듣기: 3.333초. 촬영 원본 SHA256 `4ef5ffddb8206633ee4318d0ba30649903f1930cb9f8246fba4528956000b413`.
- 실제 앱 화면 · 처음 설정에서 관심사 고르기: 3.333초. 촬영 원본 SHA256 `a0e012e329dee38bd1712ecfafaabe0d997491510f8e6ed25be1062b6eee0789`.
- 실제 앱 화면 · 읽기 체험 · 직접 눌러 이어하기: 4.500초. 촬영 원본 SHA256 `c8d3da3ad2ecbc9c2752235f44c56c836df3db4a32d83ff2934e1287c27ee786`.

진행을 저장하고 다시 직접 눌러 이어하는 흐름을 보여 준다. 돌아오자마자 자동으로 마이크·음성이 재개된다고 표현하지 않는다. 앱 화면 영상은 무음으로 녹화했고, 앱 첫 인사 원음을 포함한 영화의 음성·음악 믹스는 별도로 합쳤다. 화면 속 Nova는 시연용 가상 별명이다. 앱의 주행 지원과 실제 Pleos 차량 허용은 아직 검증되지 않았다.

## 목소리와 원고

가상의 오누 B2 참조는 자체 생성했다. 사람의 목소리 녹음이나 아이의 대화를 수집하지 않았다. 첫 인사 8.48초는 앱에 적용한 같은 WAV가 입력이며, 나머지 7개 32.96초는 같은 B2 참조로 따로 만든 소개 대사다. 앱의 동적 별명·다른 이야기까지 모든 발화가 같은 동봉 음원이라는 뜻은 아니다.

## 음악과 효과음

배경음 ‘Onu — A Small Companion / 0.47 arrangement’는 기존 원작 합성 방식으로 새로 구성한 자체 음악이다. seed 20261105, 72bpm, Cadd9–Am7–Fmaj7–Gsus2의 느린 화성 위에 사인파 배음·잔잔한 pluck과 stereo pan을 합성했다. 외부 곡·stock 음악·연주 녹음을 샘플링하지 않았다. 말 아래에서 배경음이 낮아지고, 쉬기 장면은 밀도를 줄인다. 시작과 마지막에 페이드를 적용했다.

숲 효과는 bolland의 [Forest ambience.aiff](https://freesound.org/people/bolland/sounds/196005/)를 사용한 [Uebergame 공개 OGG 재배포본](https://github.com/RenxoAr/Uebergame/blob/master/art/sound/environment/forest/wind_forest_birds_01.ogg)에 기반한다. 물 효과는 Siddharth Patil(Ksd5 / Sidpatil)의 [Swale](https://commons.wikimedia.org/wiki/File:Swale.ogg)에 기반한다. 두 원본은 [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)이며 앱에서 발췌·필터·페이드·음량 조절·혼합한 파일을 영상에서 낮게 배치했다. 원저자와 사이트의 후원이나 보증을 뜻하지 않는다. 발견 효과는 기존 자체 절차 합성의 0.8초 세 음이다. 이번 영상은 공룡 목울음 효과를 사용하지 않는다.

## 그림과 글꼴

오누와 일곱 이야기 세계의 기존 앱 그림을 사용했다. 차창 일러스트는 기존 오누 그림을 참조해 imagegen으로 제작한 기존 키비주얼이며 이번 작업에서 다시 생성하지 않았다. 해당 키비주얼 SHA256은 `2af26a9a6bfb748037c0f78eb069c3ff268631d7a29eaab324f57748bd76014b`다. 이번에는 카메라 거리·구도·밝기·빛선·느린 움직임을 새로 합성했다. 글꼴은 Noto Sans KR을 영상에 렌더했다. 등장인물을 실제 아이의 촬영으로 표시하지 않는다.

## 기술 검수와 남은 확인

최종 영상 전체 오류 중단 디코드, 1920×1080·30fps·1860프레임, AAC와 한국어 자막, 전체 길이와 자막 경계가 통과했다. 최종 영상 측정치는 -18.20 LUFS / -2.44 dBTP다. 선택한 최종 프레임을 모델이 직접 열어 가독성·배치·실제 UI 고지를 확인했다. 최종 영상 SHA256은 `855fa08b8aa06dcd99d09ab310cfda81e7b597074d1767e58c84e1dd755892e8`다.

목표는 약 −18 LUFS, true peak −2 dBTP 이하다. 2-pass loudness 측정/마스터링 후 압축 결과를 다시 측정한다. 자막은 전체 WAV 안에서 문장 길이에 비례해 나눈 근사 타이밍이며 강제 정렬이나 사람 확인이 아니다. 한 줄 26자·최대 두 줄과 시간 범위를 검사한다.

기술 검사와 모델의 프레임 검토는 사람 청취·실제 아동의 이해와 재미·물리 마이크·실제 차량 스피커·주행 안전/허용 검증을 대신하지 않는다. 목소리 자연스러움과 차내 사용 검증은 남아 있다.
